Learn SketchNet

Everything you need to design neural networks visually.

Quick Start Guide

Follow these three steps to build your first model in SketchMod.

1. Place Nodes

Click a node in the left toolbar — like Layer — then click on the canvas to place it. Every model needs at least an Input Data, a Layer, an Output, and an Optimizer.

2. Connect Ports

Drag from an output port (right side of a node) to an input port (left side). SketchNet automatically propagates tensor shapes and shows you the data flow.

3. Configure & Export

Select the Optimizer to set your loss function and training parameters. Click Check to validate your graph, then Export to download a runnable .py file.

The Phase System

SketchNet splits your graph into three execution phases. Each port carries checkboxes that tell the code generator when that port is active.

Preprocessing Preprocessing

Data loading, normalisation, one‑hot encoding, and train/test splits happen here. Preprocessing runs once before training starts.

Training Training

Model layers, loss computation, and weight updates. The training loop runs for the number of epochs you specify in the Optimizer.

Evaluation Evaluation

Runs the trained model on test data. Visualizations, accuracy nodes, and DeOneHot belong here.

Pro tip: Use the Highlight Path button to colour‑code your graph by phase.

Node Reference

Input Data

Loads a CSV, Excel, JSON, or Parquet file. Attach a dataset from the properties panel or enter a shape manually.

Layer / Neuron

A fully‑connected linear layer. Set the number of neurons and activation function. Accepts multiple inputs (they are concatenated along the feature dimension).

Conv2D

2‑D convolution. Specify filters, kernel size, stride, padding, and activation.

Output

Defines the model's outputs. Three ports: loss (used during training), prediction and evaluation (used during evaluation).

Optimizer

Configures loss function, optimizer type, learning rate, batch size, epochs, early stopping, and validation split.

Accuracy / Print / Visualization

Analytics nodes that run during evaluation (Accuracy, Print) or any phase (Print in preprocessing). Visualizations support 1‑D, 2‑D, and 3‑D scatter plots with discrete or continuous colour mapping.

Common Patterns

Click any link to open a pre‑built graph on the canvas. You only need to replace the dataset.

  • Linear Regression – Input → ColumnSelect → Layer → Output → Optimizer (MSE)
  • Binary Classification – Input → ColumnSelect → Layer → Output(softmax) → Optimizer(CrossEntropy) → Accuracy
  • Image Classifier (CNN) – Input → Reshape → Conv2D → Flatten → Layer → Output → Optimizer
  • Skip Connection – Input → Layer → Layer → Add ← Layer (skip) → Output

Templates are empty — you'll need to attach your own dataset in the Input Data node.

Troubleshooting

"Missing Input Data node"

Add an Input Data node from the toolbar. Every model needs one.

"Optimizer node must be in the training phase"

Select the Optimizer's input ports and ensure Training is checked in the properties panel.

"CrossEntropyLoss requires 1‑D integer labels"

Insert a Reshape node between your label column and the Optimizer with target shape (-1).

Model doesn't converge

Try increasing the learning rate or epochs. For classification, make sure your labels are integers (0, 1, 2, …). For Conv2D models, ensure the input shape is (batch, channels, height, width).

"Data‑flow cycle detected"

Your graph contains a loop — the output of a node eventually feeds back into itself. Remove one of the links in the cycle.
