Learn SketchNet

Everything you need to design neural networks visually.

Quick Start Guide

Follow these three steps to build your first model in SketchMod.

1. Place Nodes

Click a node in the left toolbar — like Layer — then click on the canvas to place it. Every model needs at least an Input Data, a Layer, an Output, and an Optimizer.

2. Connect Ports

Drag from an output port (right side of a node) to an input port (left side). SketchNet automatically propagates tensor shapes and shows you the data flow.

3. Configure & Export

Select the Optimizer to set your loss function and training parameters. Click Check to validate your graph, then Export to download a runnable .py file.

The Phase System

SketchNet does not assign nodes to phases — any node can participate in any phase. Instead, ports carry phase checkboxes. A node is active in a phase only when its inner circuit is complete for that phase.

How a node becomes active

A node's inner circuit is active when:

  • At least one data input port carries the phase, AND
  • The corresponding output port also carries the phase

For conjunctive nodes (Add, Optimizer, Visualization, Accuracy), all connected data inputs must carry the phase — not just one.

Intersecting ports are output ports from the preprocessing set that also carry a training or evaluation phase. They act as seeds that start the training/evaluation subgraph. Without them, data cannot flow from preprocessing into training or evaluation.

Preprocessing Preprocessing

Data loading, normalisation, one‑hot encoding, train/test splits, and row/column selection. Runs once before training. Use the Highlight Path → Preprocessing button to see which nodes are active.

Training Training

Model layers, loss computation, and weight updates. Begins at preprocessing output ports that carry the training phase.

Evaluation Evaluation

Runs the trained model on test data. Visualizations, Accuracy, and DeOneHot belong here.

⚠️ Evaluation must enter the model at the same point as training

The trained model is reused during evaluation — so the first model node in the evaluation phase must be the same node as in the training phase. If evaluation enters the model at a different node, it will be skipped. Use a MultiPort and connect both the train and test data streams to the same input port.

Node Reference

Input Data

Loads a CSV, Excel, JSON, or Parquet file. Attach a dataset from the properties panel or enter a shape manually. The output port carries the raw data tensor — typically 2‑D (rows, columns) for tabular data, but can also be 3‑D or higher for image data.

Data Restructuring Nodes

These nodes reshape and filter your data before it enters the model.

  • Column Select — pick specific columns by index or range (e.g. 0, 2:5). Use it to separate features from labels.
  • Row Select — keep only certain rows (first‑N, random sample, slice, or specific indices).
  • Dim Select — slice along arbitrary dimensions. Useful for selecting channels or spatial regions.
  • Reshape — change the tensor shape. Use -1 for one inferred dimension, and keep symbolic names like batch if needed.
  • Flatten — collapse all dimensions except the batch into one feature vector.
  • Train / Test Split — randomly split data into training and evaluation sets.
  • Normalize — standard (Z‑score) or min‑max scaling. Param ports share statistics between train and test.
  • OneHot Encode / DeOneHot — convert class indices to one‑hot vectors and back. Param ports share the category list.
  • Concatenate — join multiple tensors along a specified axis.

Layer / Neuron

A fully‑connected linear layer. Set the number of neurons and activation function. Accepts multiple inputs — they are concatenated along the feature dimension (dim=1). Batch sizes must match across all inputs.

Conv2D

2‑D convolution. Specify filters, kernel size, stride, padding, and activation. Expects input shape (N, C, H, W).

Dropout / BatchNorm / Add

Dropout — randomly zeroes activations during training (rate configurable). BatchNorm — normalises activations across the batch. Add — element‑wise addition of two tensors (used for skip/residual connections). Both inputs must have identical shapes.

Output

Defines the model's outputs. Three ports: loss (raw logits, used during training), prediction (e.g. softmax, used during evaluation), evaluation (e.g. argmax, used during evaluation). Configure activations per port in the properties panel.

Optimizer

Configures loss function, optimizer type (Adam, SGD, AdamW), learning rate, batch size, epochs, gradient clipping, early stopping, and validation split. Two inputs: loss (from Output) and labels (from your data pipeline).

Accuracy / Print / Visualization

Accuracy — computes classification accuracy and optionally a confusion matrix. Print — prints tensor shapes and values to the console (useful for debugging). Visualization — scatter plots (1‑D, 2‑D, 3‑D) with discrete or continuous colour mapping.

Common Patterns

Click any link to open a pre‑built graph on the canvas. You only need to replace the dataset.

  • Linear Regression - Input → ColumnSelect → Layer → Output → Optimizer (MSE)
  • Binary Classification - Input → ColumnSelect → Layer → Output(softmax) → Optimizer(CrossEntropy) → Accuracy
  • Image Classifier (CNN) - Input → Reshape → Conv2D → Flatten → Layer → Output → Optimizer
  • Skip Connection - Input → Layer → Layer → Add ← Layer (skip) → Output

Templates are empty — you'll need to attach your own dataset in the Input Data node.

Troubleshooting

"Missing Input Data node"

Add an Input Data node from the toolbar. Every model needs one.

"Missing Output node"

Add an Output node and connect your model's last layer to it.

"Optimizer node must be in the training phase"

Select the Optimizer's input ports and ensure Training is checked in the properties panel.

"No optimizer node — training loop will not be generated"

Add an Optimizer node and connect it to the Output's loss port and your label data.

"Preprocessing does not reach training or evaluation"

Make sure at least one output port from preprocessing (e.g. a Train/Test Split) has Training or Evaluation checked. These are the intersecting ports that bridge phases.

"CrossEntropyLoss requires 1‑D integer labels"

Insert a Reshape node between your label column and the Optimizer with target shape (-1).

"Evaluation will be skipped because it cannot reuse the trained model"

Evaluation must enter the model at the same node as training. Connect both train and test data to the same input port using a MultiPort.

"Batch sizes must match when feeding into the same model node"

When a Layer or Neuron has multiple inputs, all inputs must have the same batch size (first dimension). Use Row Select or adjust your split ratios to match them.

"Multiple training entry points detected"

Your model has two nodes that receive training data but are not connected to each other. Merge the data streams or remove one entry point.

"Data‑flow cycle detected"

Your graph contains a loop — the output of a node eventually feeds back into itself. Remove one of the links in the cycle.

"Param‑port cycle detected"

Two Normalize (or OneHot) nodes are referencing each other's statistics, creating a circular dependency. Break the cycle by removing one param‑port link.

Model doesn't converge

Try increasing the learning rate or epochs. For classification, make sure your labels are integers (0, 1, 2, …). For Conv2D models, ensure the input shape is (batch, channels, height, width). If using ReLU activation, try switching to Linear first to check if activations are dying.

Accuracy is 0.5 (binary) or 0.33 (3‑class) — random guessing

Your model is not learning. Check that: (1) the features actually contain information about the labels, (2) the label column is correctly selected, (3) the learning rate is not too low, (4) the labels are properly reshaped to 1‑D for CrossEntropyLoss.
