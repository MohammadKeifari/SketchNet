Learn SketchNet

A beginner-friendly guide to SketchNet and the SketchMod editor.

Quick Start

You need a free SketchNet account to open SketchMod. Once signed in, follow these four steps.

1. Add your data

Upload a dataset under Data, or pick one when you configure an Input Data node in SketchMod.

2. Draw the graph

Open SketchMod, place nodes from the left toolbar, and connect output ports (right) to input ports (left). Every trainable model needs Input Data, at least one layer, an Output, and an Optimizer.

3. Check the graph

Click Check. SketchNet validates connections, shapes, and phases before anything is exported. Fix any errors shown in the dialog.

4. Export PyTorch code

Click Export to download a .py file or a .zip bundle (script plus dataset). The generated script has four clear parts: load_data(), Model, train(), and evaluate() — no hidden dictionaries or runtime branching.

How It Works

SketchNet runs your graph in three stages. You control which stage each port belongs to using the phase checkboxes in the properties panel.

Prepare data Preprocessing

Load CSV/Excel data, split train/test, normalize features, and encode labels. This runs once when the script starts.

Train the model Training

Layers, loss, and the optimizer run here. Data must reach the model through ports that carry the Training phase.

Test the model Evaluation

Accuracy, plots, and predictions run on test data. Use ports marked Evaluation.

One important rule

Training and testing must enter the same layer — connect both train and test tensors to the same input port (purple multi-input ports accept several links). If test data enters at a different layer, evaluation is skipped.

Nodes

Nodes are grouped by what they do. Select a node in SketchMod to edit it in the right sidebar.

Data

  • Input Data — load a dataset or synthetic tensor.
  • Column / Row Select — pick features and labels.
  • Train / Test Split — separate training and test rows.
  • Normalize — scale features (statistics can be shared with test data).
  • OneHot / DeOneHot — encode and decode class labels.
  • Reshape / Flatten — change tensor shape before the model.

Model layers

  • Layer / Neuron — fully connected layer with an activation.
  • Conv2D — convolution for image-like inputs.
  • Dropout / BatchNorm / Add / Concat — regularization, normalization, skip connections, merging branches.
  • Output — defines loss, prediction, and evaluation outputs.

Training

  • Optimizer — loss type, learning rate, epochs, batch size, early stopping.

Results

  • Accuracy — classification score (optional confusion matrix).
  • Visualization — scatter or histogram plots.
  • Print — debug tensor shapes in the console.

Advanced

  • Dim Select — slice along extra dimensions.
  • Param ports (dashed links) — share normalization or category lists between nodes.

Starter Templates

Each link opens a ready-made graph in SketchMod. Attach your own dataset to the Input Data node.

  • Linear Regression — predict a number from features (MSE loss).
  • Binary Classification — two-class prediction with CrossEntropy and Accuracy.
  • Image Classifier (CNN) — reshape flat pixels, convolve, classify.
  • Skip Connection — residual-style Add between two branches.

Help

Missing Input Data node

Add an Input Data node — every graph needs a data source.

Missing Output node

Add an Output node when training. Connect your last layer to it.

Optimizer not in training phase

The Optimizer must be reachable in the Training phase. Check phase boxes on its ports and upstream links.

No optimizer / no training loop

Add an Optimizer, connect the Output loss port and your label tensor.

Preprocessing does not reach training or evaluation

Mark at least one preprocessing output port with Training or Evaluation so data can flow forward.

Evaluation cannot reuse the trained model

Connect train and test data to the same model input port (purple multi-input).

Data-flow or param-port cycle

Remove a link that creates a loop. Param links (dashed) must not circle back.

Model does not learn

Check label column selection, learning rate, epochs, and that labels are 1-D integers for CrossEntropyLoss.
